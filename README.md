# Learning Management System

This repository contains a **Learning Management System (LMS)** developed as the final cumulative assignment for **ENSF 381 – Full Stack Web Development**.

The project brings together the front-end and back-end concepts covered throughout the course into a functional web application where users can create accounts, log in, view courses, enroll in courses, and manage their enrollments.

## Features

### User Authentication

Users can:

- Create a new account through the Sign Up page
- Log in using their account credentials
- Access features available to authenticated users

### Course Management

Users can:

- View available courses
- Enroll in a course
- View courses they are currently enrolled in
- Drop courses from their enrollment

### Home Page

The home page introduces the Learning Management System and includes:

- Information about the platform
- An About Us section
- Student testimonials
- Navigation to other areas of the website

### Interactive User Interface

The application contains multiple pages and interactive elements, including:

- Login forms
- Sign-up forms
- Navigation buttons
- Course enrollment controls
- Course drop controls
- Dynamic course information

## Technologies Used

The project was developed using technologies introduced throughout ENSF 381, including:

- HTML
- CSS
- JavaScript
- Node.js
- Flask
- REST APIs
- Server-side routing
- Client-server architecture

## Project Background

This LMS was developed progressively through the ENSF 381 assignments.

Earlier assignments introduced individual front-end and back-end concepts, while **Assignment 5 combined these components into the completed Learning Management System**.

The goal of the project was to demonstrate how the different layers of a web application work together to provide a functional and interactive user experience.
